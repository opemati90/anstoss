## Platform admin console (`apps/admin`)

Sections: Overview, Clubs, Users, Subscriptions, Health, Settings. Auth is
username + scrypt password with rate-limited login and a session token held in
`sessionStorage`; every `/admin/*` call is proxied through nginx with the
session header and guarded server-side. Headers are stricter than the site
(no-store, noindex). No findings beyond the dependency majors above. The in-app
club admin (owners/admins in the mobile app) was rebuilt today as the club
workspace with counts.
