# Anstoss Mobile — Full UI / UX / Accessibility Audit

**Date:** 2026-06-11 · **Scope:** all 93 route screens in `apps/mobile/app/`
**Method:** 6 parallel read-only audit agents (one rubric) → consolidated → Codex adversarial validation (read primitives + sampled offenders directly).
**Yardstick:** `DESIGN.md` + `src/theme/*` + `src/components/ui/*` primitives.

---

## Verdict

**Block MVP only for the 2 confirmed P0s. Everything else is ship-then-iterate.**

The app is NOT a mess — the design system, tokens, and primitives are mature, and several screens are exemplary (`league-table`, `dm-list`, `match-live`, `pending-approval`, `access-blocked`). The inconsistency is **adoption drift**: newer/one-off screens hand-roll what the primitives already provide. That's fixable mostly by centralizing at the primitive level, not by rewriting 93 screens.

The icon library is clean — **0 route screens import `@expo/vector-icons` directly** (the "different icons" you see is fill/outline drift + header divergence, not library fragmentation).

## P1 — visible inconsistency (ship-then-iterate), by prevalence

### 1. Raw `<TextInput>` instead of the `FormInput` primitive — ~30 screens (~91 raw usages)
`FormInput` exists (`src/components/FormInput.tsx`) and `SearchBar` exists (`src/components/ui/SearchBar.tsx`) but most forms bypass both, each re-declaring `input: { height 52/56, borderWidth, borderRadius, fontSize }` → border/height/focus/error styling drifts screen-to-screen.
Offenders: edit-profile, exchange, ehrenamt, invite, free-agent/[id], free-agent/profile, fussball-link, join-code, join/[...code], dm-new, sign-in, about, dob, name, phone, club-create, club-identity, club-search, roster-build, admin-contribution-plan, admin-members, admin-sponsors, carpool, club-setup, create-event, (tabs)/roster, sportgericht, team-management, transfer-list, voice-memos, pitch-status, player-loan, notification-settings, enter-dob.

### 2. "Fonts too small" — CONFIRMED — hardcoded `fontSize` below the 12px caption floor
Floor: `caption` = 12; `micro` = 10 is **legal/distance fine-print only**.
- **9px (worst):** `(tabs)/events` dayChipDow `L1261`, `lineup-builder` tokenName `L1140`, `scouting` `L678`, `streaks` `L626`.
- **10px non-legal:** match-detail livePulseText `L1191`, photo-wall crownText `L491`, pitch-status microLabel `L449`, sportgericht (×3), trikotwart `L547`, vereinsheim `L443`, voice-memos (×3), conflicts `L595`, my-contributions, team-families.
- **11px UI labels:** about, club-create, club-identity, done, carpool (eyebrow/section/seats), more sectionTitle, compliance, (tabs)/events sectionHeader.
Codex severity note: P1, not P0 (none is mandatory copy). Many offenders carry an `eslint-disable … TODO Pass 3 migrate` banner = **known deferred debt**.

### 3. Hardcoded `fontSize` literals bypassing `<Text variant>` — ~40+ screens
Text component is used, but styled ad-hoc in StyleSheet instead of via `TextStyles` variants → line-height/letter-spacing/weight decouple from the type ramp. Heaviest: `(tabs)/roster` (~55 decls), scouting, sportgericht, streaks, trikotwart, vereinsheim, voice-memos, carpool, admin-contribution-plan.

### 4. Root-wrapper / header inconsistency — the "screens look different" issue
- **5 of 7 tab screens don't use `<Screen>`.** 4 different header treatments across 5 tabs: chat builds its own header View, squad builds a hero View, roster uses `TabScreenHeader`, events/home/more rely on the bespoke club header in `(tabs)/_layout.tsx`.
- **6 bucket-F one-offs** (scouting, sportgericht, streaks, trikotwart, vereinsheim, voice-memos) use `ModalHeader` + manual `paddingBottom` instead of `<Screen>`. **Safe-area-correct** (ModalHeader adds top inset), so consistency-only — not a safety bug.
- `(tabs)/roster` ships a bespoke `Modal` edit sheet **next to** a canonical `BottomSheet` in the same file.

### 5. Accessibility — missing labels + sub-44px touch targets
- **Missing `accessibilityLabel` on icon-only/interactive controls:** ~10 onboarding screens (about, dob, done, free-agent-profile, name, role, roster-build, roster-claim, team-code, team-code-share), exchange (7 Pressables/1 label), free-agent/profile (12/6), transfer-list (6 of 9), voice-memos (3/6), trikotwart, event-detail `<Switch>` `L297`, find-club club badge `<Image>` `L116`, photo-wall user `<Image>`s `L253/327`, scouting avatar `<Image>` `L360`.
- **Sub-44px touch targets (Codex bumped these up):** dm-chat send 36×36 `L315`, admin-contribution-plan stepper 32×32 `L944`, trikotwart rows 32/36 `L603/L662`, welcome chips (hitSlop 6/8).

### 6. Bespoke `<Modal>` re-implementing the `BottomSheet` primitive
welcome (2: dev + language picker `L223/L269`), admin-billing (`L699`), create-event `PickerSheet` (`L633` — deliberate iOS-spinner host, lowest priority).

### 7. Settings-list 3-way fork (drawer/menu consistency)
`legal` (row 15px/600/56h), `notification-settings` (15px/500/56h), `language` (callout/64h) each hand-roll a different settings row instead of the shared `ListRow` primitive. The More tab also hand-rolls its `Section`/`RowView` list.

### 8. Hardcoded hex breaking dark mode (genuine ones only)
`(tabs)/squad` avatarInit `#FFFFFF` `L312`, `(tabs)/invites` `#FFFFFF` `L305`, transfer-list `#FFFFFF` `L787`, voice-memos `#fff`/`#000` `L328/904`, events shadowColor `#0F1116`, lineup-builder pitch/jersey `#fff`+rgba (conventionally OK on a green pitch, low priority).
**NOT violations (corrected by Codex):** role/club-identity/done/club-setup color arrays are **preset brand-swatch palettes** = sanctioned data, not chrome.

## What a static audit could NOT catch — needs runtime/simulator verification
- Dynamic Type at 200% — many screens have fixed heights/`numberOfLines` that will clip.
- Dark-mode contrast on custom overlays / non-theme surfaces (welcome modals, bespoke sheets).
- RTL layout (left/right assumptions in custom rows).
- Keyboard-avoidance on screens with custom modals + multiline inputs.
- Actual clipping behavior of the squad P0.

---

## Highest-leverage remediation order (Codex-validated: max surface, min churn)

**Phase 0 — P0s (now, before MVP):** fix squad clearance + notification Switch label. ~2 small edits.

**Phase 1 — centralize at the primitive (fix once, propagate):**
1. **`TabScreen` wrapper** built on `<Screen>` with safe defaults (padding, StatusBar, `tabBarClearance`) → fixes all tab roots' clearance + header divergence in one place. (Resolves P0 #1 + systemic #4.)
2. **a11y-enforced icon-action primitive** (`IconButton` variant) that bakes in `accessibilityLabel` (required prop), 44×44 min hit area, hitSlop → fixes the whole sub-44 + missing-label class as screens adopt it.
3. **Lint guardrails:** `no-restricted-syntax` rules flagging raw `<TextInput>` (→ FormInput), raw `fontSize:` in StyleSheet (→ Text variant), and raw hex in component color props. Stops new drift + drives the migration.

**Phase 2 — per-screen sweeps (low-risk, mechanical):**
4. Settings rows → `ListRow` (legal, language, notification-settings, more). One pattern.
5. Forms → `FormInput`/`SearchBar`, screen group by screen group.
6. Typography sweep: kill all sub-12px non-legal fonts; migrate raw `fontSize` → variants (the "Pass 3" debt).
7. Bespoke `<Modal>` sheets → `<BottomSheet>` (welcome, admin-billing).

**Reference exemplars to copy from:** `league-table.tsx` (data tables), `dm-list.tsx` (list + icon buttons), `match-live.tsx` (clean primitives), `pending-approval.tsx`/`access-blocked.tsx` (clean Screen usage).
